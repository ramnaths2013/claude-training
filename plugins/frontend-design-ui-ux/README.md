# frontend-design-ui-ux plugin

Packages the `frontend-design-ui-ux` skill from https://github.com/ulpi-io/skills
(source commit pinned in the repo's `skills-lock.json`) so it can be installed as a plugin.
All skill content belongs to its original authors; check that repo's licence before redistributing.

Note: this project's `CLAUDE.md` forbids frameworks and external resources. When using the skill here,
ask for plain CSS custom-property tokens only.
